Eligibility firewall

One-way value migration.

Commercial origin → industrial use

  • May retain industrial, marine, training or core value
  • Can open new markets when aviation demand is limited
  • Commercial eligibility remains only when independently documented

Industrial / marine → commercial aircraft

  • Blocked by default
  • No promotion based on appearance, lineage or similar numbering
  • Requires verified identity, configuration, trace, life records and acceptable release documentation
