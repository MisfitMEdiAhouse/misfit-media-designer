Eligibility firewall

One-way value migration.

IALS protects the value of legitimate inventory by refusing to blur commercial, industrial, marine and military histories.

Commercial origin → non-flight use

  • May retain industrial, marine, training, research, display or core value.
  • Commercial eligibility remains only when independently supported.
  • Alternate markets can unlock value without misrepresenting history.

Industrial / marine → commercial aircraft

  • Blocked by default.
  • No promotion based on appearance, shared lineage or similar numbering.
  • Requires verified identity, configuration, trace, life records, condition and acceptable release documentation.
