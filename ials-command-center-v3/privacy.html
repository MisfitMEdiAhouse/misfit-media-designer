Data handling

Private means private.

IALS separates public inventory marketing from private customer, repair-partner, purchase-order, compliance and transaction records.

Public site

Public pages may display general capabilities, engine programs, part numbers, NSNs, alternate numbers and verification-pending inventory records. They do not publish signed End User Certificates, customer pricing, payment-card information, private repair-partner terms, controlled technical data or confidential customer records.

Private operations

Private records should be stored only in an authenticated, access-controlled, encrypted system with appropriate retention, backup and audit controls. The current static admin preview uses browser-local storage and must not be treated as a secure production repository.

Analytics

The prototype may store local browser events such as inventory searches, part views and RFQ actions for testing. Production analytics requires a published privacy policy, consent controls where applicable and configured analytics accounts.
